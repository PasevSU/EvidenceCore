# Release checklist

This is a public source snapshot with proposed commercial terms; it is **not** a certified production release.

- [ ] Confirm authorship and redistribution rights for all project code and examples.
- [ ] Verify third-party notices, provenance, MPL/GPL/LGPL implications if applicable, and binary licensing.
- [ ] Remove client data, EML, private keys, credentials, forensic case identifiers and embedded local paths.
- [ ] Run secret and personal-data scans against all files and repository history.
- [ ] Verify main script and PDF engine parse cleanly on supported PowerShell editions.
- [ ] Run malformed-input, HTML injection, filesystem path and untrusted-data tests.
- [ ] Verify optional dependencies and update all installation instructions.
- [ ] Confirm SHA-256 values for a finalized, immutable release artifact.
- [ ] Finalize commercial agreement, invoicing, tax, consumer rights and support terms.
- [ ] Separate tests/demos from real evidence and redact logs.
- [ ] Create versioned release notes and record known limitations.

Do not market checkout, automatic license activation or third-party certification as implemented when absent.
